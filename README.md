# Wholesas Knights' Legacy

Wholesas Knights' Legacy is a Minecraft mod that adds 100 unique knight armor sets to the game. Each set has the same quality as the epic knights mod and provides armor ratings on par with netherite. This mod is designed for Fabric 1.21.11 and offers a variety of armor sets to enhance your gameplay experience.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft and ensure the mod is loaded correctly.

## Use

1. After installing the mod, launch Minecraft.
2. Open your inventory and navigate to the crafting menu.
3. Use the crafting recipes provided by the mod to create the knight armor sets.
4. Equip the armor sets to enjoy the enhanced protection and unique designs.
